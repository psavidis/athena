# Contributing

## Proposing a change

Open an issue before starting work, using the right template under
[`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/) (bug report, feature
request, or task). This gives the change a ticket to track and link back
to from the PR.

## Branch naming

Use a short, kebab-case branch name that includes the ticket number, e.g.
`142-refresh-token-before-expiry`.

## Pull requests

Every PR must use the repo's
[PR template](.github/PULL_REQUEST_TEMPLATE.md): a Conventional-Commits
title (`type(scope): description`), and a body that links back to its
ticket via `Related-to: #<ticket-number>`.
