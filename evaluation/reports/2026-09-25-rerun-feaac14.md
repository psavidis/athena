## Findings

1. **J1: Returns of anonymous classes and lambdas are garbled.** #339 trims the before/after
   return expressions at token level, which breaks on class bodies and lambdas:
   - guava-8647 `Multisets#union`/`intersection`/`sum`: `return Set<E> createElementSet -> public Set<E> elementSet`. These are fragments of the anonymous class's members, not a returned value. This is misleading: before #339 it correctly said "other statements changed".
   - error-prone-6105 `MoreAnnotations#asStrings`: `return x -> x != null -> Objects::nonNull`. The lambda arrow and the before/after arrow can't be told apart.
2. **J2: Multiple returns repeat the same phrase.** mockito-3843 reads `return value changed, return value changed`, and `MoreAnnotations#asStrings` lists the same lambda twice. Identical items should be listed once, perhaps with a count.
3. **J3: Trimmed expressions leave dangling fragments.**
   - vertx-6367 `NetServerImpl#actualPort` reads `return server != null ? server.actualPort : -> ref == null ? 0 : ref.get().`, cut mid-expression with a trailing `.`.
   - `sniEntrySize` and `sslContextProvider` read `return nothing -> …` where the base's return was restructured, not absent.
   - Trims should stop at balanced expression boundaries, or fall back to `return value changed`.
4. **J4: Maven build configuration isn't read.** dropwizard-11325's two unrepresented poms change
   `maven-dependency-plugin` and enforcer configuration: the PR's actual workaround. They are
   out of scope for #340 (plugins and properties) and are the next step if build files matter.
5. **Still open from the baseline:**
   - H6 (Groovy/Spock tests unread, micronaut-13421).
   - The #338 follow-up: spring-security has no rail between `config` and `web`, because they reference each other through project names.

## Limitations

- **In-sample.** The second expansion drove #334–#340, so its gains measure fix correctness,
  not generalization.
- **Single agent evaluator,** as before. The re-scored entries were judged by the same agent that implemented the fixes, so the second-expansion gains deserve an independent look.
- **Only changed views were re-scored.** An entry whose Athena output is identical keeps its
  previous score.
